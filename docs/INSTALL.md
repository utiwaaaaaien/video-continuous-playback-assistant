# 视频连续播放助手 V3.1

1. 解压发布包，保留course-player-assistant文件夹。
2. Chrome打开chrome://extensions，开发者模式下加载该文件夹。旧版替换原安装目录文件后点击重新加载，再刷新课程页。
3. 开启连续播放、自动确认、跨课程和保持唤醒。浏览器拒绝自动播放时先点击网站播放按钮。
4. 原Mac唤醒组件2.1.0继续使用，无需重装。新电脑可运行附带的mac-wake-helper安装脚本。

播放失败或人工问题在2分钟无人操作后刷新一次；题目和验证码也刷新一次，可能丢失未提交的输入。开始点击或输入会取消该倒计时。刷新后仍失败会提示并发送浏览器通知。

网络错误每2分钟刷新一次，最多3次，最终失败则停止本标签、通知并释放唤醒，系统按现有设置自动锁屏。通知显示受Chrome/macOS设置影响，页面提示同时保留。

详细说明及验证范围见course-player-assistant内README.md和TEST-REPORT.md。

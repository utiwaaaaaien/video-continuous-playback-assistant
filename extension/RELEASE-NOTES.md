# 视频连续播放助手 V3.1

日期：2026-10-06。扩展版本：3.1.0。发布形式：本地扩展包。

- 播放失败或等待人工处理时，2分钟无人操作后自动刷新当前播放页一次。刷新后最多观察60秒，通过实际视频时间前进确认恢复；仍失败则停留人工处理状态并发送Chrome通知。
- 答题、验证码、未知弹窗也刷新一次。课程页点击、按键、输入或点击通知会取消倒计时；刷新可能清空未提交的输入。助手仍需用户完成题目和验证码。
- 网络错误调整为每2分钟刷新，最多3次，每次观察30秒；恢复后取消剩余重试，最终失败时通知用户、停止本标签并释放唤醒，由现有系统设置自动锁屏。
- 按标签保存已使用的刷新次数，避免刷新重置或页面与后台重复执行。停止、换课程、换视频、关闭标签会取消旧计划；旧页面记录不能覆盖已经执行的刷新状态。

保留目录全部完成后跨课程、未完成视频补播、三色状态灯、圆角界面及Mac本地保护。原Mac唤醒组件2.1.0无需重装，补充同一网站的主机权限，用于后台读取标签地址及核对刷新目标。内容脚本仍只匹配播放页。

验证范围见TEST-REPORT.md。Chrome定时可能延迟，系统通知展示受Chrome和macOS设置影响。使用Chrome官方接口：[alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms)、[notifications](https://developer.chrome.com/docs/extensions/reference/api/notifications)。

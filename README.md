<h1 align="center">视频连续播放助手</h1>
<p align="center">Chrome · macOS · V3.1<br>自动续集、遗漏补播、故障恢复与播放状态提醒</p>

面向 macOS Chrome 的课程视频连续播放扩展，目前适配 **中国教育干部网络学院** 的 `estudy.enaea.edu.cn/web/player/*` 播放页。目录中所有视频明确显示“完成”后，自动进入下一个课程；“全一集”、普通标题或文件名目录都可以使用。

A macOS Chrome extension for continuous course playback, automatic episode switching, missed-video replay, and bounded recovery. Currently supports the player pages on estudy.enaea.edu.cn.

**[下载 V3.1](https://github.com/utiwaaaaaien/video-continuous-playback-assistant/releases/tag/v3.1.0)** · [安装说明](docs/INSTALL.md) · [更新说明](CHANGELOG.md) · [验证记录](docs/VALIDATION.md)

## 可以做什么

| 功能 | 行为 |
| --- | --- |
| 连续播放 | 按目录顺序切集，并回到遗漏的未完成视频继续播放 |
| 跨课程续播 | 所有目录项显示“完成”后，点击“下一个课程”并继续播放，不依赖集号 |
| 提示确认 | 自动关闭已识别的欢迎和继续播放提示；题目、验证码由用户完成 |
| 两类进度 | 同时显示视频时间进度与网站目录完成百分比 |
| 直观状态 | 展开、收起和工具栏面板显示红黄绿状态灯及当前状态 |
| 播放唤醒 | Chrome 电源保护配合可选 Mac 本地组件，播放时维持唤醒 |
| 故障恢复 | 人工问题无人响应时刷新一次；网络错误最多刷新三次 |
| 浏览器通知 | 恢复后仍失败时发送人工处理通知，点击可返回对应标签页 |

## 安装 V3.1

1. 在 [Releases](https://github.com/utiwaaaaaien/video-continuous-playback-assistant/releases/latest) 下载 V3.1 ZIP 并解压，保留解压后的文件夹。
2. Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 **course-player-assistant** 文件夹。
4. 返回已登录的课程播放页，刷新页面，点击“开始连续播放”。按需要开启自动确认、跨课程和保持唤醒。

已有版本：替换原安装目录文件，在扩展管理页点击“重新加载”，再刷新课程页并检查启用状态。浏览器阻止自动播放时，先点击网站播放按钮。

直接使用本仓库源码时，在 Chrome 中加载 **extension** 文件夹。扩展无需编译、Node.js 或服务器；Node.js 仅用于开发测试。

Mac 本地唤醒组件需单独安装：运行发布包中的 `mac-wake-helper/安装Mac唤醒组件.command`，填入该扩展在 Chrome 中的 ID。原组件 **2.1.0** 可继续使用，不必重装。[组件原理、安装及移除](mac-wake-helper/README.md)。

## V3.1 的恢复规则

| 场景 | 自动处理 | 仍未恢复时 |
| --- | --- | --- |
| 播放失败、未知弹窗、答题或验证码 | 连续播放启用后，2 分钟无人操作则刷新当前页一次；刷新后最多核验 60 秒 | 保留人工处理状态，发送浏览器通知，不再重复刷新 |
| 网络错误 | 每 2 分钟刷新一次，最多 3 次；每次最多核验 30 秒 | 停止当前标签、通知用户、释放该标签的唤醒保护 |

在课程页点击、按键、输入或点击通知，会取消人工问题的刷新倒计时。主动暂停不会触发该恢复计划。停止助手、换课程或换视频会取消旧计划。恢复成功以视频时间实际前进为准，刷新次数不会因重载而重置。

答题和验证码刷新可能丢失尚未提交的输入，请及时操作。欢迎提示在自动确认开启时自动点击“知道了”，随后尝试恢复播放。网络三次失败后，Mac 按原有系统设置自动锁屏；若其他标签仍正常播放，它们的唤醒保护保留。

## 状态灯与完成判断

- **绿色**：助手已启用、视频正在播放，相关选项和浏览器/本地保护均正常。
- **黄色**：视频正在播放，但部分选项关闭或唤醒保护未就绪。
- **红色**：未播放、未启用、暂停、等待人工处理或等待网络恢复。

是否需要继续播放，以网站目录明确显示“完成”或“已完成”为准。仅显示 100% 数字不视为完成；已经完成的视频，即使播放条只到 90% 多，也可继续下一集或下一课程。

## 支持范围与权限

当前版本只适配上述网站的播放页，未作为通用视频网站插件发布。网站结构变化或新的提示样式可能需要更新。自动播放受 Chrome 策略约束；通知展示受 Chrome/macOS 设置影响；后台调度与系统睡眠可能延迟重试。手动锁屏、合盖和企业策略仍由系统处理。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存按标签隔离的会话、选项及刷新次数 |
| `notifications` | 发送人工处理提醒 |
| `power` | 临时请求屏幕和系统保持唤醒 |
| `alarms` | 调度恢复及清理过期唤醒请求 |
| `nativeMessaging` | 与可选 Mac 本地唤醒组件通信 |
| `https://estudy.enaea.edu.cn/*` | 后台读取该网站标签地址，核对刷新目标；内容脚本只匹配播放页 |

扩展不调用外部服务，不采集或上传账号、题目和课程内容；不设置播放器时间、不修改服务器完成状态，也不自动答题或完成验证码。本地组件不修改系统锁屏设置，无需管理员或辅助功能权限。

使用 Node.js 26 或更高版本：

```sh
npm install
npm test
```
